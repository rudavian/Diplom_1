# Diplom_1

Юнит-тесты для проекта Stellar Burgers.

## Проверяемая область

Основной объект проверки — класс `Burger`.

Дополнительно проверены связанные классы и основной сценарий запуска, чтобы подтвердить 100% покрытия проекта.

## Реализованные проверки

- установка булки;
- добавление ингредиента;
- удаление ингредиента;
- перемещение ингредиента;
- расчёт стоимости бургера;
- формирование рецепта;
- работа с mock-объектами;
- параметризованная проверка расчёта стоимости;
- работа с объектами `Bun` и `Ingredient`;
- использование данных из `Database`;
- запуск основного сценария `praktikum.py`.

## Стек

- pytest
- pytest-cov

## Установка зависимостей

`pip install -r requirements.txt`

## Запуск автотестов

`pytest -v --cov=. --cov-report=term-missing`

## Результат

Автотесты проходят, покрытие — 100%.
